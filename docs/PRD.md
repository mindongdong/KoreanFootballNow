## 1. Executive Summary

### 제품명

**코리안 풋볼 나우 (Korean Football Now, KFN)**

### 한 줄 요약

> 코리안리거에 대한 해외 반응을 AI로 요약해 기사와 뉴스레터로 발행하고, 분석의 바탕이 된 데이터와 해석 논리를 투명하게 제공하는 미디어 기반 매치 데이터 플랫폼

### 핵심 가치 제안

"검증된 팩트와 반응만 남깁니다."

KFN은 경기 직후 흩어진 퍼블릭 데이터를 자동으로 수집하여 가장 읽기 편한 AI 요약 기사 및 뉴스레터로 즉시 제공합니다. 더 깊은 정보가 필요한 유저는 '근거 보기'를 통해 분석에 사용된 핵심 스탯과 AI의 데이터 해석 논리(Reasoning)를 직관적으로 확인하고, 이를 추가 가공 없이 웹사이트 화면 그 자체를 즉시 고품질 영상 소스로 활용할 수 있습니다.

## 2. 문제 정의

### 2.1 축구 크리에이터의 비효율 (Pain Point 1)

| 항목 | 내용 |
|------|------|
| **대상** | 유튜버, 칼럼니스트 등 축구 콘텐츠 크리에이터 |
| **현상** | 신뢰할 수 있는 해외 현지 반응과 전문 데이터를 수집, 번역, 교차 검증하는 데 **제작 시간의 70% 이상**을 소모 |
| **근본 원인** | 데이터가 다수의 플랫폼(Reddit, X, 해외 매체)에 분산되어 있고, 수작업 번역과 교차 검증 프로세스가 비효율적 |
| **영향** | 콘텐츠 생산 속도 저하, 정보 신뢰도 리스크, 높은 리서치 인건비 |

### 2.2 헤비 축구팬의 정보 피로 (Pain Point 2)

| 항목 | 내용 |
|------|------|
| **대상** | 코리안리거에 높은 관심을 가진 헤비 축구팬 |
| **현상** | 자극적인 낚시성 기사와 커뮤니티의 정보 노이즈에 피로감 |
| **근본 원인** | 국내 축구 미디어의 클릭 유인 구조, 해외 원문 접근의 언어 장벽 |
| **니즈** | 시간 낭비 없이 **'진짜 현지 민심'과 '팩트'** 만 빠르고 정확하게 파악 |

### 2.3 해결 방안 요약

| 고객 | 문제 | KFN의 해결 방안 |
|------|------|----------------|
| 축구 크리에이터 | 정보 수집과 번역에 시간 소모 | 영상 소스로 즉시 활용 가능한 팩트 데이터와 AI 해석 논리 제공 (**리서치/제작 시간 70% 단축**) |
| 헤비 축구팬 | 낚시성 기사와 정보 노이즈 피로 | 흩어진 해외 현지 반응을 한눈에 볼 수 있는 깔끔한 **AI 요약 기사 및 뉴스레터** |

## 3. 타겟 사용자

### 3.1 Primary Persona: 축구 크리에이터 (B2B)

- **프로필**: 유튜버, 블로거, 칼럼니스트 등 축구 콘텐츠 제작자
- **행동 패턴**: 매주 2~5편의 콘텐츠를 제작하며, 각 콘텐츠당 3~5시간의 리서치 시간 소요
- **핵심 니즈**: 리서치 시간 절감, 신뢰도 높은 데이터 소스, 영상/글에 즉시 활용 가능한 시각화 자료
- **결제 의향**: 리서치 인건비 대비 합리적인 월 구독료

### 3.2 Secondary Persona: 헤비 축구팬 (B2C)

- **프로필**: 코리안리거에 대한 높은 관심과 정보 소비 욕구를 가진 팬
- **행동 패턴**: 경기 직후 해외 반응을 검색하며, 커뮤니티/뉴스를 매일 확인
- **핵심 니즈**: 노이즈 없는 팩트 기반 정보, 빠른 현지 반응 파악
- **결제 의향**: 무료 콘텐츠 소비 후 OTT/티켓/굿즈 구매 시 자연스러운 전환

### 3.3 Tertiary Persona: 코리안리거에 관심 있는 해외 팬

- **프로필**: 한국 선수가 속한 리그의 해외 팬층
- **잠재 확장 시장**: 향후 영문 서비스 확장 시 타겟

## 4. 제품 비전 및 목표

### 4.1 제품 비전

코리안리거에 대한 해외 반응과 데이터를 **가장 신뢰할 수 있고, 가장 빠르게, 가장 투명하게** 전달하는 No.1 미디어 플랫폼

### 4.2 단기 목표 (3개월)

- AI 기사 생성 파이프라인 완성 (Reddit/X → OpenAI → 자동 발행)
- 뉴스레터 구독자 1,000명 달성
- 주간 AI 요약 기사 자동 발행 안정화

### 4.3 중기 목표 (6개월)

- B2B SaaS 유료 구독 출시 (Evidence View 프리미엄)
- 시즌 타임라인 대시보드 런칭
- 크리에이터 파트너 10명 확보

### 4.4 장기 목표 (12개월)

- 커머스 제휴(Affiliate) 수익 모델 가동
- 월간 활성 사용자(MAU) 10,000명
- 영문 서비스 베타 출시

## 5. 핵심 기능 요구사항

### 5.1 AI 여론 요약 기사 & 뉴스레터

**우선순위**: P0 (Must-have)

#### 기능 설명

경기 직후 레딧(Reddit), 엑스(X) 등의 해외 현지 반응을 수집해 노이즈를 제거하고, 핵심 여론만 압축한 콘텐츠를 웹과 메일함으로 즉시 발행합니다.

#### 기사 구성 요소

| 요소 | 설명 |
|------|------|
| 경기 요약 | 스코어, 주요 이벤트, 선수 활약 요약 |
| 해외 현지 반응 | 플랫폼별 AI 요약 (Reddit 서브레딧별, X 트렌드, 현지 매체 인용) |
| AI 분석 요약 | 핵심 스탯 기반 종합 분석 |
| 메타데이터 | 선수명, 팀, 리그, 매치 정보, 발행일, 태그 |
| 썸네일 | 기사 대표 이미지 |

#### 뉴스레터 구성 섹션

| 섹션 | 설명 |
|------|------|
| WELCOME | 주간 인사 |
| SNAPSHOT | 주간 핵심 요약 |
| TOP3 | 이번 주 TOP3 선수 |
| POSITION | 포지션별 하이라이트 |
| FORM | 폼 상승/하락 선수 |
| SPOTLIGHT | 주목할 선수 |
| INJURIES | 부상 현황 |

#### 수용 기준

- [ ] 경기 종료 후 2시간 이내 기사 자동 생성
- [ ] Reddit, X 최소 2개 플랫폼 반응 수집
- [ ] 노이즈(비방, 무의미 댓글) 필터링률 90% 이상
- [ ] 뉴스레터 주 1회 자동 발행
- [ ] 신규 구독자에게 최신 뉴스레터 자동 발송

### 5.2 데이터 근거 보기 (Evidence View)

**우선순위**: P0 (Must-have)

#### 기능 설명

요약 기사의 투명성과 팩트 체크를 위해, 바탕이 된 실제 경기 스탯과 AI가 여론을 도출해 낸 해석 논리(Reasoning)를 상세 페이지로 제공합니다.

#### 구성 요소

| 요소 | 설명 |
|------|------|
| 차트 시각화 | Bar, Radar, Line, Pie 차트 (Recharts 기반) |
| Data & AI 해석 논리 | 데이터 항목별 수치 + AI의 해석 근거 텍스트 + 데이터 출처 |
| 광고 큐레이션 | 기사 맥락에 맞는 OTT/티켓/유니폼 상품 |

#### 수용 기준

- [ ] 기사당 최소 2개 이상의 차트 시각화 제공
- [ ] 각 데이터 항목에 AI 해석 논리 및 출처 명시
- [ ] 크리에이터가 화면 캡처로 즉시 영상 소스 활용 가능한 시각적 품질
- [ ] 차트 데이터는 OpenAI를 통해 비정형 데이터에서 정형 JSON으로 자동 파싱

### 5.3 시즌 타임라인 대시보드

**우선순위**: P1 (Should-have)

#### 기능 설명

시즌 진행에 따라 매 라운드별 요약 기사와 선수 평점 변화를 한눈에 파악할 수 있도록 리스트 형태로 시각화합니다.

#### 수용 기준

- [ ] 라운드별 기사 리스트 표시
- [ ] 선수별 평점 변화 추이 차트
- [ ] 특정 라운드 클릭 시 해당 기사로 이동

### 5.4 선수 스탯 대시보드

**우선순위**: P0 (Must-have) — **구현 완료**

#### 기능 설명

해외파 코리안리거 전체의 주간 스탯과 상세 프로필을 제공합니다.

#### 구성 요소

| 요소 | 설명 | 상태 |
|------|------|------|
| 필터 패널 | 리그(다중), 포지션(단일), 부상 여부 필터 | 완료 |
| 스탯 테이블 | 11개 컬럼 정렬 가능 (데스크톱) | 완료 |
| 플레이어 카드 | 아코디언 형태 (모바일) | 완료 |
| 선수 프로필 모달 | 4탭(개요/공격/패스/수비), 백분위 등급 | 완료 |

### 5.5 이메일 구독 시스템

**우선순위**: P0 (Must-have) — **구현 완료**

#### 기능 설명

사이트 Footer에서 이메일 구독/해지가 가능하며, 구독 시 최신 뉴스레터를 즉시 발송합니다.

#### 수용 기준

- [x] 이메일 유효성 검증
- [x] 중복 구독 방지
- [x] 신규 구독자에게 최신 뉴스레터 자동 발송
- [x] 구독 해지 기능
- [x] 100건 배치 발송 (대량 발송 대응)

### 5.6 광고 큐레이션 (Ad Curation)

**우선순위**: P2 (Nice-to-have)

#### 기능 설명

기사에서 소비 중인 선수/팀과 자연스럽게 매칭되는 상품을 큐레이션합니다.

| 유형 | 설명 | 예시 |
|------|------|------|
| OTT | 스포츠 중계 OTT 가입 유도 | 쿠팡플레이, SPOTV NOW |
| Ticket | 직관 티켓 대행 연계 | 해외 축구 직관 패키지 |
| Merchandise | 정품 유니폼/굿즈 구매 | 선수 유니폼, 팀 굿즈 |

## 6. 비즈니스 모델

### 6.1 수익화 전략: 트래픽 기반 2-Way 수익화 구조

AI 여론 요약 기사와 뉴스레터를 대중에게 **전면 무료(Freemium)** 로 개방하여 압도적인 팬덤 트래픽을 빠르게 선점합니다. 확보된 트래픽을 바탕으로 다음 두 가지 핵심 수익을 창출합니다.

### 6.2 수익 모델 1: 크리에이터용 데이터 구독 (B2B SaaS)

| 항목 | 내용 |
|------|------|
| **대상** | 유튜버, 칼럼니스트 |
| **제공 가치** | Evidence View 내의 심층 스탯 대시보드와 AI 세부 해석 논리 열람 권한 |
| **가격 전략** | 월 구독제 (리서치 인건비 대비 합리적 가격) |
| **핵심 가치** | 리서치 인건비 대체, 콘텐츠 제작 시간 70% 단축 |

### 6.3 수익 모델 2: 헤비 팬 타겟 커머스 연계 (Affiliate)

| 항목 | 내용 |
|------|------|
| **대상** | 데이터를 깊게 파고드는 고관여 헤비 팬 |
| **수익 구조** | 기사(선수)와 매칭되는 상품 큐레이션 → 중개 수수료 |
| **상품 유형** | 스포츠 중계 OTT 가입, 직관 티켓 대행, 정품 유니폼 구매 링크 |
| **핵심 전략** | 유저가 소비 중인 기사(선수)와 자연스럽게 매칭 |

|-----------|------|

| **핵심 활동** | 해외 현지 반응 수집/번역, AI 요약 기사 및 해석 논리 생성, 뉴스레터 발행 |
| **핵심 자원** | 100% 자동화 데이터 파이프라인(n8n), AI 연동 데이터 분석, 영상 최적화 시각화 UI(Recharts) |
| **가치 제안** | 소스부터 논리까지 팩트로 읽는 해외 반응, 즉시 활용 가능한 데이터 소스, 노이즈 제거된 여론 요약 |
| **고객 관계** | 무료 기사로 유입 → 데이터 구독 전환 → 뉴스레터 리텐션 |
| **채널** | 웹 플랫폼, 이메일 뉴스레터 |
| **고객 세그먼트** | 축구 크리에이터(B2B), 헤비 축구팬(B2C), 해외 팬(잠재) |
| **비용 구조** | OpenAI API 사용료, n8n/Vercel 호스팅 비용 |
| **수익 흐름** | B2B SaaS 구독(크리에이터), Affiliate 수수료(헤비 팬 커머스) |

## 8. 기술 아키텍처

### 8.1 기술 스택

| 레이어 | 기술 | 선정 이유 |
|--------|------|-----------|

### 8.3 데이터 접근 패턴: API-first + CSV Fallback

모든 데이터 조회는 3단계 계층으로 안정성을 보장합니다:

| 계층 | 방식 | 조건 |
|------|------|------|
| 1차 | 인메모리 캐시 | 5분 TTL 이내 |
| 2차 | Google Sheets API | 8초 타임아웃 |
| 3차 | CSV 정적 파일 | 네트워크 장애 시 최후 방어선 |

클라이언트에서도 동일 패턴 적용: API 호출(10초 abort) → CSV fetch fallback

| 권한 | SYS_ADMIN | Chromium 샌드박스 |

### 9.3 FotMob 스크래퍼

- **입력**: 선수 목록 JSON (stdin 또는 파일)
- **처리**: 선수별 FotMob 페이지 접근 → `__NEXT_DATA__` SSR JSON 추출
- **출력**: JSON 배열 (`playerInfo`, `apiResponse`, `team`, `league`, `duration`, `timestamp`)
- **안티 디텍션**: 커스텀 UA, 뷰포트, 로케일(ko-KR), 타임존(Asia/Seoul)
- **레이트 리밋**: 선수 간 1~3초 랜덤 딜레이

### 9.4 AI 여론 정제 (OpenAI ChatGPT)

| 처리 단계 | 입력 | 출력 |
|-----------|------|------|
| 노이즈 필터링 | 원본 댓글/트윗 | 의미 있는 반응만 추출 |
| 여론 요약 | 필터링된 반응 | 플랫폼별 요약 텍스트 |
| 해석 논리 생성 | 스탯 + 여론 | AI Reasoning 텍스트 |
| 차트 데이터 파싱 | 비정형 데이터 | 정형 JSON (Recharts 호환) |
