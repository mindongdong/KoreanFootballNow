## 0. 서비스 포지셔닝

### KFN이 하는 것

> **"한국 해외파 전체가 지금 어떤 상황인지 한눈에 보고, 해외 여론/맥락까지 알려주는 서비스"**

| 역할 | 설명 |
|------|------|
| **스냅샷 대시보드** | 30명 해외파의 **현재 시점** 스탯을 한 곳에서 비교 |
| **AI 뉴스/여론 요약** | 해외 매체 반응을 한국어로 요약하여 데이터에 맥락 부여 |
| **뉴스레터** | 주간 단위로 큐레이션된 해외파 리포트 발송 |

### KFN이 하지 않는 것

| 영역 | 이유 | 대안 |
|------|------|------|
| 과거 시즌 아카이브 | FotMob/네이버와 차별점 없음 | FotMob 링크로 위임 |
| 폼 추이 그래프 (히스토리) | 데이터 축적 경쟁은 기존 서비스에 열위 | 뉴스/여론이 폼 변화 맥락 제공 |
| 선수 간 비교 기능 | 스냅샷 서비스 범위 초과 | FotMob 비교 기능으로 위임 |
| 전 세계 모든 선수 커버 | 30명 해외파 큐레이션이 핵심 가치 | — |

### 경쟁 서비스 대비 차별점

| 기존 서비스 | 잘하는 것 | KFN과의 관계 |
|------------|-----------|-------------|
| **FotMob** | 개별 선수 상세 스탯, 히스토리, 슈팅맵 | KFN은 상세 스탯을 FotMob 링크로 위임. "30명을 각각 찾아볼 필요 없이 한 곳에서" |
| **네이버 해외축구** | 한국어 경기 일정/결과, 리그별 순위 | KFN은 "한국 해외파"라는 횡단면 뷰 제공. 리그를 넘나드는 비교 |

### 데이터 전략

- **수집**: 매일 최신 스냅샷만 수집 (히스토리 축적 안 함)
- **제공**: 현재 시즌 누적 + 최근 5경기 집계
- **깊이보다 맥락**: 데이터의 깊이는 FotMob에 맡기고, KFN은 "왜 이 데이터가 의미 있는지"를 뉴스/여론으로 설명

## 2. "최근" 지표의 정의

### 확정 사항

| 항목 | 결정 |
|------|------|
| 기준 경기 수 | **최근 5경기** |
| 포함 대회 | **전체** (리그 + 컵 + A매치 + 유럽대항전) |
| 테이블 표시 값 | **최근 5경기 평균/합산** (평점=평균, 골/AS=합산) |
| 5경기 상세 보기 | **프로필 모달 안**에서 개별 경기 목록 표시 |
| 기준 표기 방식 | **테이블 상단 안내 텍스트** (예: "※ 최근 지표는 최근 5경기 기준입니다") |

### 현재 코드와의 갭

현재 구현은 `player.recent_match`(가장 최근 1경기)만 사용 중. 변경 필요:
1. `recent_matches_json` (5경기 JSON)을 파싱하여 5경기 집계값(평균 평점, 합산 골/AS, 합산 출전시간) 계산
2. 테이블 컬럼의 데이터 소스를 1경기 → 5경기 집계로 변경
3. 프로필 모달에 최근 5경기 목록 섹션 추가 (상대팀, 결과, 평점, 골, AS 등)


## 4. 데이터 수집 출처 및 시점

### 확정 사항

| 항목 | 결정 |
|------|------|
| 출처 | **FotMob** |
| 수집 주기 | **매일 오전 9시 (KST)** |
| 표시 위치 | **테이블 하단** ("총 N명의 선수" 옆) |
| "주간" 개념 | **뉴스레터에서만 사용**. 대시보드는 매일 최신 데이터 |

### 테이블 하단 표기 예시

```
총 30명의 선수 · FotMob 기준 · 2026.02.23 09:00 업데이트
```

`collection_date` 필드를 활용하여 수집 시점을 동적으로 표시.

## 8. 향후 검토 사항

스냅샷 + 뉴스 포지셔닝 범위 내에서 검토 가능한 항목:

| 항목 | 상태 | 비고 |
|------|------|------|
| 슈팅 데이터 시각화 | 향후 결정 | 현재 스냅샷 데이터 내 13개 필드 활용 (발별/상황별 차트) |
| 골키퍼 전용 프로필 | 향후 대응 | GK 추적 선수 발생 시 대응 |

**명시적 제외** (서비스 포지셔닝과 충돌):

| 항목 | 제외 이유 |
|------|-----------|
| 폼 추이 그래프 | 히스토리 데이터 축적 → FotMob 열화판. 뉴스/여론이 폼 맥락 대체 |
| 선수 간 비교 | 스냅샷 범위 초과. FotMob 비교 기능으로 위임 |
| 과거 시즌 아카이브 | 데이터 축적 경쟁 불필요 |

## 9. 구현 변경사항 요약

현재 코드 대비 변경이 필요한 항목:

### 즉시 변경 (v1)

1. **`recent_matches_json` → 5경기 집계 계산**: `csvParser.ts` 또는 `dataHelpers.ts`에서 5경기 평균 평점, 합산 골/AS/출전시간 계산 로직 추가
2. **테이블 컬럼 데이터 소스 변경**: `StatsTable.tsx`에서 `player.recent_match`(1경기) → 5경기 집계값 사용
3. **기본 정렬 적용**: `StatsDashboard.tsx`에서 `sortConfig` 초기값을 `{ key: 'player_name_kr', direction: 'asc' }` 로 변경
4. **테이블 상단 안내 텍스트 추가**: 시즌 기준, 최근 지표 기준 표기
5. **테이블 하단 정보 추가**: 수집 출처(FotMob), 수집 시점(`collection_date`) 표시
6. **프로필 모달에 최근 5경기 목록 추가**: `recent_matches_json` 파싱하여 개별 경기 정보 표시
7. **모바일 정렬 드롭다운 추가**: `FilterPanel.tsx` 또는 별도 컴포넌트로 모바일 정렬 UI

### 확인 후 변경

8. **백분위 tooltip 수정**: FotMob 백분위 기준 확인 후 정확한 표현으로 수정
