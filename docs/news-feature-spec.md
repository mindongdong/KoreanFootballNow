> **문서 상태**: v1.0 확정
> **작성일**: 2026-02-23
> **목적**: 뉴스/여론 기능의 콘텐츠 전략, 생성 파이프라인, UI/UX 방향을 확정

---

## 0. 서비스 포지셔닝과의 관계

> **Stats 대시보드**: 30명 해외파의 현재 시점 스냅샷
> **뉴스/여론**: 그 데이터에 **맥락과 의미**를 부여하는 콘텐츠

Stats가 "무엇이 일어났는가"를 보여준다면, 뉴스/여론은 "왜 그것이 의미 있는가"를 설명합니다.

| 역할 | 설명 |
|------|------|
| **해외 여론 번역/요약** | Reddit, X, 현지 매체의 반응을 한국어로 전달 |
| **경기 맥락 제공** | 스탯 숫자 너머의 경기 상황과 평가 전달 |
| **Evidence 기반 분석** | 데이터 차트와 AI 해석으로 객관적 근거 제공 |

---

## 1. 콘텐츠 범위

### 확정 사항

| 항목 | 결정 |
|------|------|
| 기사 유형 (MVP) | **경기 후 활약 기사만** |
| 비경기 기사 (이적/부상/이슈) | **향후 추가** (MVP 이후) |
| 기사 주제 범위 | 추적 중인 30명 해외파 선수의 경기 활약 |
| 발행 빈도 | **경기 있을 때마다** (해당 선수 경기 종료 후) |

### MVP 이후 확장 예정

- 이적 소식 기사
- 부상/복귀 기사
- 대표팀 소집/A매치 관련 기사
- 시즌 중간 리뷰/전망 기사

## 2. 기사 생성 파이프라인

### 확정 사항

| 항목 | 결정 |
|------|------|
| 생성 방식 | **AI 자동 생성** (최소 인적 개입) |
| AI 모델 | **GPT API** (OpenAI) |
| 트리거 | **n8n 워크플로우 확장** (기존 FotMob 스크래핑 인프라 활용) |
| 품질 관리 | **선택적 검토** (자동 발행 → 사후 수정/삭제 가능) |

### 생성 파이프라인 흐름

```
경기 종료 감지 (n8n)
  → FotMob 경기 데이터 수집
  → 여론 수집 (Reddit + X + 현지 매체)
  → AI가 원문 번역 + 요약 (한국어)
  → GPT API로 기사 생성 (3단 구조)
  → GPT API로 Evidence 차트 데이터 구성
  → Static JSON 파일로 저장
  → 자동 발행 (사이트에 반영)
```

### 여론 수집 소스

| 소스 | 수집 대상 | 특성 |
|------|-----------|------|
| **Reddit** | 관련 서브레딧 (r/soccer, 리그별 서브) | 팬 커뮤니티 반응, 상세 분석 |
| **X (Twitter)** | 해당 선수/팀 관련 트윗 | 실시간 반응, 짧은 코멘트 |
| **현지 매체** | 리그 소속국 언론 기사 | 전문가 평가, 공식 보도 |

### 다국어 처리

- AI가 영어/독일어/프랑스어 등 원문을 **한국어로 번역 + 요약**
- 원문 출처 링크 제공 (신뢰도 확보)

## 3. 기사 콘텐츠 구조

### 확정 사항

| 항목 | 결정 |
|------|------|
| 기사 구조 | **3단 유지** (경기요약 + 해외여론 + AI분석) |
| 여론 표현 방식 | **출처별 그룹핑** (Reddit / X / 현지매체 구분) |

### 기사 본문 구조

```
## 경기 요약
- 경기 결과, 선수 활약상, 주요 장면
- FotMob 경기 데이터 기반

## 해외 여론
### Reddit
- 팬 커뮤니티 반응 요약 (한국어 번역)

### X (Twitter)
- 실시간 반응 요약 (한국어 번역)

### 현지 매체
- 언론 평가 요약 (한국어 번역, 출처 명시)

## AI 분석
- 데이터 기반 객관적 분석
- 시즌 맥락에서의 경기 의미
- Evidence View 연결
```

## 4. Evidence View

### 확정 사항

| 항목 | 결정 |
|------|------|
| Evidence View | **현재 구조 유지** (별도 페이지, KFN 차별점) |
| 차트 데이터 생성 | **AI가 데이터 구성** (FotMob + 여론 데이터 결합) |
| 차트 유형 | bar, radar, line, pie (Recharts 활용, 현재 구현 유지) |

### Evidence View 콘텐츠

- **차트**: AI가 기사 내용에 맞는 차트 데이터 구성 (최대 4개)
- **DataRow**: AI 해석 논리 (데이터 포인트별 설명)
- **면책 조항**: 공개 소스 기반 데이터임을 명시

## 5. 데이터 저장 및 서빙

### 확정 사항

| 항목 | 결정 |
|------|------|
| MVP 저장 방식 | **Static JSON/MD 파일** |
| 확장 시 | **DB (Supabase/PostgreSQL 등)로 전환** |
| 서빙 방식 (MVP) | 빌드 시점에 정적 파일 로드 |

### MVP 데이터 구조

```
kfn-app/src/data/articles/
  ├── index.json          # 기사 목록 메타데이터
  ├── 2026-02-23-son.json # 개별 기사 (본문 + Evidence)
  ├── 2026-02-23-lee.json
  └── ...
```

### 개별 기사 JSON 스키마 (예시)

```json
{
  "id": "2026-02-23-son-heungmin",
  "title": "손흥민, 리버풀전 1골 1도움 맹활약",
  "subtitle": "EPL 라운드 26 토트넘 vs 리버풀",
  "playerIds": ["son-heungmin"],
  "league": "Premier League",
  "matchDate": "2026-02-22",
  "publishedAt": "2026-02-23T09:00:00+09:00",
  "summary": "...",
  "content": "## 경기 요약\n...\n## 해외 여론\n...\n## AI 분석\n...",
  "evidence": {
    "charts": [...],
    "dataRows": [...]
  },
  "adCurations": [...],
  "sources": [
    { "type": "reddit", "url": "...", "title": "..." },
    { "type": "x", "url": "...", "title": "..." },
    { "type": "media", "url": "...", "title": "...", "outlet": "The Guardian" }
  ]
}
```

## 6. Stats 대시보드 연결

### 확정 사항

| 항목 | 결정 |
|------|------|
| 연결 방식 | **양방향 연결** |

### 연결 구현

**Stats → 뉴스**:
- 선수 프로필 모달 내 "관련 기사" 섹션 추가
- `playerIds` 필드로 기사-선수 매칭

**뉴스 → Stats**:
- 기사 내에서 해당 선수의 Stats 카드/요약 표시
- 프로필 모달 열기 링크 제공

## 7. 기사 목록 UI

### 확정 사항

| 항목 | 결정 |
|------|------|
| 레이아웃 | **현재 Featured + Grid 유지** |
| 필터링 | **선수/리그 필터** 제공 |
| 정렬 | 최신순 (시간순) |
| 태그 체계 | **선수 + 리그만** (기사 유형 태그는 향후) |
| 콘텐츠 수명 | **무기한 유지** (목록에서 시간순으로 자연스럽게 밀려남) |

### 필터 UI

Stats의 `FilterPanel`과 유사한 패턴:
- 리그 필터: 체크박스 (리그별)
- 선수 필터: 드롭다운 또는 검색

## 9. 뉴스레터 연계

### 확정 사항

| 항목 | 결정 |
|------|------|
| 뉴스레터 관계 | **뉴스레터가 기사 포함** (기사의 이메일 버전) |
| 주간 뉴스레터 | 해당 주 주요 기사 전문을 포함하여 발송 |

### 연계 흐름

```
주간 기사 생성 (경기마다)
  → 주말에 해당 주 기사 중 하이라이트 선별
  → 뉴스레터 템플릿에 기사 전문 포함
  → Resend API로 발송
```

## 11. 구현 변경사항 요약

### 즉시 변경 (MVP)

1. **Static JSON 기사 데이터 구조 정의**: `article.ts` 타입 업데이트, `data/articles/` 디렉토리 구조
2. **기사 목록 필터 추가**: `ArticleList.tsx`에 선수/리그 필터 UI
3. **여론 섹션 출처별 그룹핑**: `ArticleView.tsx` 본문 렌더링에서 Reddit/X/현지매체 구분 표시
4. **양방향 연결 구현**: 프로필 모달 → 관련 기사, 기사 → 선수 Stats 카드
5. **n8n 워크플로우 확장**: 경기 종료 감지 → 데이터 수집 → AI 생성 → JSON 저장
6. **GPT API 연동**: 기사 생성 + Evidence 차트 데이터 구성

### 확장 단계

7. **DB 전환**: Static JSON → Supabase/PostgreSQL
8. **비경기 기사 추가**: 이적/부상/이슈 기사 유형 및 태그 체계
9. **기사 검색**: 전문 검색 기능
